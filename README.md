# LearnTrack — TeachTech Learning Dashboard

A colorful, responsive dashboard for organizing courses and keeping track of your learning.

## Features

- Create courses and add topics to each course.
- Mark topics complete and see course progress update automatically.
- Plan study sessions on a monthly calendar.
- Write daily learning notes linked to a course topic, then reopen them by selecting the topic.
- Save your own questions and answers.
- Switch between colorful light and dark themes.
- Keep courses, schedules, notes, Q&A, and theme preference in your browser with local storage.

## Built with

- HTML
- CSS
- Vanilla JavaScript

No framework, database, server, or build step is required.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

For a local development server, you can also use the Live Server extension in Visual Studio Code.

## Deploy with Netlify

This is a static site and can be deployed without a build command:

1. Sign in to [Netlify](https://www.netlify.com/).
2. Create a new site by importing this repository, or use Netlify Drop to upload the project folder.
3. If asked for build settings, leave the build command empty and set the publish directory to the project root.

Netlify will provide a public site URL after deployment.

## Data and privacy

Learning data is stored in local storage in the visitor's browser. It is not sent to a database or shared with other visitors. Data is specific to the browser and device where it was entered; clearing browser storage or using a different browser/device will not carry it over.
